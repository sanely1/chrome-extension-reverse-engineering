# GitHub Copilot Instructions for Chrome Extension Privacy Extraction

## Project Context

This workspace step is for extracting declared privacy information from Chrome Web Store privacy pages for browser extensions.

The goal is to produce structured, reproducible JSON output describing what the developer publicly declares about data collection and data usage in:

1. the Chrome Web Store privacy section
2. the developer's external privacy policy, if such a link is available on the Chrome Web Store privacy page

This step does **not** analyze extension source code. It only runs the local `fetch_privacy.py` script and verifies the generated JSON output.

---

## Quick Start

**To begin privacy extraction, use this prompt:**

```
Begin Chrome extension privacy extraction. Extension ID: [EXTENSION_ID]. Run fetch_privacy.py and verify the generated JSON output.
```

## Core Principles

### Execution-First Rule

* You **MUST execute** the local Python script `fetch_privacy.py`
* You **MUST NOT simulate** privacy data
* You **MUST NOT invent** declared privacy categories, external privacy policy categories, or developer statements
* The final result must come from the JSON file generated by the script
* If execution fails, report the failure explicitly and stop

### Local-Only Execution

* Work entirely within the current workspace
* Use only the local script `fetch_privacy.py`
* Do NOT manually scrape, copy, or rewrite information from the browser
* Do NOT call unrelated external services or APIs
* Do NOT perform source-code analysis in this step

### Deterministic Output Rule

* The output JSON must be loaded from the file created by `fetch_privacy.py`
* If the expected JSON file does not exist, do not continue
* If the JSON cannot be parsed, do not continue
* If required fields are missing, document the problem and stop
* If the external privacy policy was not found or could not be retrieved, preserve the script output exactly and do not invent fallback values

## Expected JSON Structure

### Required Fields

The generated JSON must contain at least:

```json
{
  "extension_id": "...",
  "url": "...",
  "chrome_webstore_privacy_url": "...",
  "retrieved_at": "...",
  "declared_data_categories": [],
  "developer_statements": [],
  "privacy_text": "...",
  "chrome_webstore": {
    "url": "...",
    "declared_data_categories": [],
    "developer_statements": [],
    "privacy_text": "..."
  },
  "external_privacy_policy": {
    "url": null,
    "final_url": null,
    "retrieved": false,
    "error": null,
    "detected_data_categories": [],
    "developer_statements": [],
    "privacy_text": ""
  }
}
```

### Meaning of Fields

* `declared_data_categories` is the extracted category list from the Chrome Web Store privacy page
* `developer_statements` is the extracted developer statement list from the Chrome Web Store privacy page
* `privacy_text` is the extracted Chrome Web Store privacy text
* `chrome_webstore` stores the same Chrome Web Store data in a nested object for clarity
* `external_privacy_policy` stores the developer's external privacy policy, if found
* If no external privacy policy link is found, `external_privacy_policy.retrieved` must be `false`
* If an external privacy policy is found and retrieved, `external_privacy_policy.retrieved` must be `true`, and its `privacy_text` should contain the external page text

### Declared Data Categories

The field `declared_data_categories` may contain values such as:

* `personally_identifiable_information`
* `health_information`
* `financial_and_payment_information`
* `authentication_information`
* `personal_communications`
* `location`
* `web_history`
* `user_activity`
* `website_content`

### Developer Statements

The field `developer_statements` may contain values such as:

* `not_sold_to_third_parties`
* `not_used_for_unrelated_purposes`
* `not_used_for_creditworthiness`

## Failure Handling

### When Python Is Missing

If `python --version` fails:

1. Stop execution
2. Report that Python is not available
3. Do NOT attempt privacy extraction

### When Playwright Is Missing

If script execution fails because Playwright is missing:

1. Report the exact error
2. Suggest installing Playwright locally with:

```bash
python -m pip install playwright
python -m playwright install
```

3. Do NOT simulate output

### When Chrome Web Store Blocks or Redirects

If the generated JSON contains a privacy text that is clearly not the extension privacy section:

1. Report the issue
2. Mention that the page may have been blocked by Google consent, redirect, or layout changes
3. Do NOT infer declared categories manually

### When JSON Is Missing or Invalid

If `privacy_workspace/declared_privacy.json` is missing or invalid:

1. Stop execution
2. Report the issue
3. Do NOT proceed with partial data

## Exclusions

### Do Not Perform

* Do NOT analyze JavaScript source code
* Do NOT inspect `manifest.json`
* Do NOT compare declared privacy data with actual behavior
* Do NOT create `extension_summary.json`
* Do NOT create risk findings
* Do NOT infer privacy violations

### This Step Only Extracts Declared Data

This prompt is only for collecting what the developer declared on the Chrome Web Store privacy page and, if available, what the developer explains in the external privacy policy linked from that page.

Actual behavior analysis is handled by the separate Chrome extension reverse engineering prompt.

Declared-vs-actual comparison is handled by a separate comparison prompt.
